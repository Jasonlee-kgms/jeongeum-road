# 정음의 길 — 훈민정음 창제 서사 RPG

학생이 **집현전에 갓 들어온 젊은 학사**가 되어, 훈민정음이 만들어지기까지의 **일곱 걸음**을 직접 밟아 보는 중학생용 학습 게임입니다. 도트 그림으로 된 탑뷰 맵 RPG로, 저잣거리·근정전·집현전·후원 별채를 걸어 다니며 인물에게 말을 걸고, 자리를 골라 이야기를 정하고, 몰려드는 의문에 실시간으로 답합니다.

> **원작**: 「영웅의 길 — 영웅소설 서사 RPG」 (박준일, 온양여자고등학교 국어 교사)
> <https://github.com/pblsketch/hero-road>
>
> 이 저장소는 원작자의 허락을 받아 **게임 엔진·도트 그림·배경음을 그대로 쓰고, 내용만 훈민정음으로 바꾼** 교내 비영리 학습용 판본입니다. 이야기 글·문헌 자료·용어 사전은 모두 새로 썼습니다.

| 1443(창제)과 1446(반포)을 섞는다 | 6·7장이 각각 그 두 시점이고, 결과 화면에서 순서를 다시 엮는다 |
| 최만리를 단순한 훼방꾼으로 본다 | 6장에서 **여섯 조목을 하나씩 겪고**, 논변 뒤에 재평가 카드를 읽는다 |

- 브라우저만 있으면 됩니다(설치 없음). 휴대폰(가상 조이스틱)·PC(키보드)·태블릿 모두 됩니다.
- **2차시**입니다. 1차시: 서장~4장, 2차시: 5장~결과. 4장이 끝나면 "1차시는 여기까지" 안내가 나오고, 다음 시간에 타이틀의 **이어 하기**로 5장부터 이어 갑니다.
- 진행 상황은 **그 브라우저에만** 저장됩니다(서버로 보내지 않음). 같은 기기·같은 브라우저에서 이어 해야 합니다.

## 구성 (2차시)

| 장 | 걸음 | 맵에서 하는 일 | 다루는 내용 |
| --- | --- | --- | --- |
| 서장 아무도 모르는 일 | — | 저잣거리: 사관에게 말 걸기, 대서소에서 이름 적기 | 대서소, 글 모르는 백성 |
| 1장 펴지 못하는 뜻 | 1 백성의 어려움 | **(임금이 되어)** 근정전 조회 → 신문고 → 저잣거리 | **애민**, 삼강행실도의 한계 |
| 2장 빌려 쓴 글자 | 2 옛 방법의 한계 | 이두·구결·한자 세 자리를 **직접 찾아가** 읽기 | **자주**, 이두·구결 |
| 3장 소리가 나는 자리 | 3 소리를 살핌 | **(학사로 전환)** 집현전: 입술·혀·목구멍 중 한 곳에서 소리 내 보기 | 아·설·순·치·후 다섯 자리 |
| 4장 본뜨고, 획을 더하다 | 4 글자를 지음 | 후원 별채: 다섯 기본자 → **막힌 대목** → 가획 갈래 맡기 | **상형·가획**, 이체자 ㆁㄹㅿ · **1차시 끝** |
| 5장 하늘과 땅과 사람 | 5 글자를 모음 | 중성 맞추기 → 수련 → 기술 익히기 → 물건 → 연습 논변 | **삼재·초출/재출·합자·부서법** |
| 6장 상소가 올라오다 | 6 반대에 부딪힘 | 근정전: 최만리의 상소 → 답할 방식 고르기 → 앞뜰 어전 논변 | **갑자 상소 6조목**, 임금의 반박 |
| 7장 스물여덟 자를 펴다 | 7 펴냄 | 해례 집필 → 마지막 물음 → 반포 → 저잣거리 | **5해 1례**, 어제 서문, 1447~1459 문헌 |

**논변**: 잔 의문은 **붉게 번쩍이면** 곧 말이 날아옵니다. 큰 상대(최만리, 마지막 물음)는 말하기 전에 땅에 **붉은 자리**(부채꼴·곧은 줄·원)를 먼저 보여 주니 그 밖으로 비켜서고, 말이 끝난 틈에 답하세요. 답할 때마다 **설득**(막대 아래 노란 줄)이 쌓여 가득 차면 상대의 **말문이 막힙니다**(효과 1.5배). 상대가 **근거를 모으면**(노란 고리) 몰아쳐 답하거나 **궁리**로 끊어야 합니다.

**기술 나무**: 聲 소리(청탁 가리기 → 가획 → 칠음), 理 이치(삼재 → 협찬 → 궁리), 民 백성(훈민 → 유통 → 편어일용). 2단계는 그 능력치 **3 이상**, 3단계는 **5 이상**이어야 하고 앞 단계를 먼저 익혀야 합니다. 기술 이름은 모두 『훈민정음』 해례본에서 따왔고, 뜻은 편람의 **용어 사전**에 있습니다.

**반발 게이지**: 6장에서 상소에 어떻게 답하느냐에 따라 조정의 반발이 오르내립니다. 가득 차도 게임 오버는 없습니다.

**결과 화면(나의 훈민정음)**: 목차 엮기(내가 걸은 일곱 대목을 순서대로) → 처음 보는 자료 3개에서 걸음 찾기 → 표지와 목차, 사관의 셈(첫 시도 정확도), 한 줄 디브리핑 답 → **이미지로 저장**.

## 사실과 상상의 구분

| 표시 | 뜻 |
| --- | --- |
| 붉은 낙관 `原典` | 실제로 남아 있는 문헌(해례본, 세종실록, 갑자 상소, 용비어천가, 월인천강지곡, 동국정운, 언해본) |
| 한지 색 `용어와 원리` | 상형·가획·삼재·합자·부서법 같은 제자 원리와 창제 정신 |
| 청록 `게임 설정 · 虛` | 사관의 틀, **주인공(지어낸 인물)**, 인물들의 대사, 능력치, 논변 규칙, 반발 게이지 |
| 쪽빛 `해석` | 정답이 없는 질문. 채점하지 않음 |

- **주인공은 실제 인물이 아닙니다.** 세종·정인지·신숙주·성삼문·박연·최만리는 실존 인물이지만 **대사는 모두 지어낸 것**입니다. 기록에 남은 말은 임금의 반박 몇 마디뿐이고, 그 대목은 게임 안에 그대로 넣었습니다("그대는 운서를 아느냐, 사성과 칠음에 자모가 몇인지 아느냐").
- 게임 오버가 없습니다. 기력이 다하면 **임금의 말씀**으로 논변이 이어집니다.
- **최만리를 악역으로 그리지 않습니다.** 여섯 조목을 근거와 함께 제시하고, 논변 뒤에 재평가 카드를 읽게 합니다.
- 일곱 걸음은 **학계가 정한 공식 단계가 아니라** 공부하기 쉽게 이 게임이 정리한 순서입니다. 타이틀과 편람에 그렇게 밝혀 두었습니다.

## 원작에서 바꾼 것

- **내용 전부**: story·quests·maps·works·notes·people·skills·bosses·battle 데이터를 훈민정음 창제 서사로 새로 썼습니다.
- **용어**: 일대기 7단계 → 창제의 일곱 걸음 / 전기수 → 사관 / 의심 게이지 → 반발 게이지 / 천우신조 → 임금의 말씀 / 武兵術 → 聲理民 / 신물 → 임금이 내린 물건 / 적장전 → 맞논변.
- **길 나누기 제거**: 원작의 아들·딸 두 길과 세 갈래를 없애고 한 갈래로 만들었습니다(역사는 하나이므로).
- **세종 스프라이트 리컬러**: 명나라식 황색 곤룡포를 조선의 **홍룡포**로 바꿨습니다. 원본은 `assets/sprites/_orig_sp_emperor.png`에 남겨 두었습니다.
- **새 스프라이트**: `sp_courtier_boss`(최만리) — `sp_courtier`를 2배로 확대해 만들었습니다.
- **삽화 교체**: 원작의 장면 그림(`assets/sc/`)은 **중국(명나라) 복식·건축**이라 세종 시대에 맞지 않아, 조선 저잣거리 그림(`sc_market`)만 남기고 나머지는 참조를 뺐습니다. 파일은 지우지 않았으니 되돌릴 수 있습니다.
- **타이틀·미리보기 그림**: 훈민정음 기본자(ㄱㄴㅁㅅㅇ, ㆍㅡㅣ)로 새로 만들었습니다.

### 남은 한계

- **장면 삽화가 없습니다.** 저잣거리(서장·1·2·7장)를 뺀 나머지 장은 대화창에 그림 없이 진행됩니다. 조선 복식의 목판화풍 삽화를 새로 만들면 채울 수 있습니다.
- 논변은 원작의 실시간 전투를 이름만 바꾼 것이라, 화면에는 여전히 **칼을 든 동작**이 남아 있습니다. 수업에서 "베는 것이 아니라 답하는 것"이라고 한 번 짚어 주시면 좋습니다.
- 논변의 난이도 수치는 자동 플레이로만 맞췄습니다. 학생 조작 실력에 따라 `js/data/bosses.js`의 `hp`·`speed`를 조절하세요(임금의 말씀이 있어 막히지는 않습니다).
- 장 안에서의 위치는 저장하지 않습니다. 중간에 끄면 다시 열 때 그 장의 **다음 목표**부터 이어집니다.
- 사실 확인 자료 가운데 **『세종실록』 원문을 직접 열람하지 못한 항목**이 있습니다(복수의 2차 출처 대조로 정리). 배포 전 교과서와 대조해 주세요.

## 만든 것들의 출처

- **엔진·도트 그림·글꼴 서브셋 도구**: 원작 「영웅의 길」(박준일). 원작자의 허락을 받아 사용.
- **배경음**: 국립국악원 「디지털 이음」(<https://www.gugak.go.kr/digitaleum/>)의 국악기 연주 악구 — **공공누리 제1유형·출처표시**. 원작에서 그대로 가져왔습니다.
- **글꼴**: Noto Serif KR, 나눔손글씨 붓에서 게임에 쓰인 글자만 남긴 부분 글꼴 (**SIL OFL 1.1**, `assets/fonts/OFL.txt`).
- **이야기 글·문헌 카드·용어 사전·타이틀 그림**: 이 판본에서 새로 썼습니다. 인용한 『훈민정음』(1446)·『세종실록』·갑자 상소(1444)는 모두 저작권이 소멸한 자료이며, 본문은 원문을 그대로 옮긴 것이 아니라 오늘날 말로 풀어 쓴 것입니다.
- **코드**: HTML + CSS + 순수 JavaScript(빌드 도구 없음).
